# 🌐 IP Ping Checker

A simple Python networking tool that checks the connectivity of multiple IP addresses using the Windows Ping command.

## ✨ Features

- Check multiple IP addresses.
- Detect online and offline hosts based on ping responses.
- Simple and beginner-friendly Python script.
- Lightweight and easy to use.

## 🛠️ Requirements

- Python 3.x
- Windows OS

## 🚀 Usage

Run the script:

```bash
python ping_checker.py
```

## ⚙️ Configuration

Edit the `ip_list` variable to add or remove IP addresses:

```python
ip_list = ["192.168.1.1", "8.8.8.8", "1.1.1.1"]
```

## 📌 Example Output

```text
IP 192.168.1.1 is ONLINE
IP 8.8.8.8 is ONLINE
IP 1.1.1.1 is ONLINE
```

*Example output only. Actual results depend on network connectivity and firewall settings.*
